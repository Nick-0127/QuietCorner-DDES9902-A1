The archive is a retrospective preservation of existing published artifacts, not a reconstruction of the original distribution method. The forms linked to a game page that was updated over time and did not record build hashes. Therefore the exact build used by each respondent cannot be independently confirmed. This limitation must accompany comparisons rather than being replaced by a claim of verified build-level association.

The original publication records remain in the local assessment evidence. `archive_manifest.json` records the package hashes and every restored file hash. There are no participant names, individual responses or discussion screenshots in this public archive.

The existing Pages root remains the historical October A1 build. Current testing uses [Unity Play](https://play.unity.com/en/games/cb6480bf-c6c9-478d-bd55-268582bd716d/quiet-corner).
